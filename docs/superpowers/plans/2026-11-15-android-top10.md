# Android top ten implementation plan

> **For agentic workers:** Use subagent-driven development for independent file
> ownership and an independent whole-branch review before delivery.

**Goal:** Deliver ten tested runtime/build improvements in a separate branch.

**Architecture:** Retain the current NVN-to-Vulkan renderer and C guest runtime.
Change isolated arithmetic, allocator and cache policies, with existing fallback
paths and meaningful fault-injection/behavior tests.

**Tech Stack:** C11, Rust wtbuild, Python harnesses, Vulkan, Android NDK r28c.

**Spec:** `docs/superpowers/specs/2026-11-15-android-top10-design.md`.

## Global constraints

- ARM64 / NDK r28c / API 29+; no copyrighted game inputs or private artifacts.
- Preserve user saves/settings, resolution, pacing, audio and renderer feature gates.
- Never claim device performance or physical sound/fold validation from host tests.
- Keep new helper integration in the production compile path, with exact tests.
- Changes are on `improve/android-top10-20261115`, not the source branch.

## Review focus

- Stale callbacks after capture teardown/restart must not become new-run evidence.
- Integer minimum values, aliased operands and short SIMD vectors retain semantics.
- Fragmented frees and empty blocks cannot lose memory or release live resources.
- Corrupt/huge files and full-disk/close/rename failures leave a usable old cache.
- Android compile flags and freestanding headers must remain compatible together.
